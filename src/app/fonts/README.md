# OpenBoard fonts

These font files are self-hosted from Google Fonts so production builds and
runtime rendering do not depend on a request to Google Fonts.

- Inter: [Google Fonts](https://fonts.google.com/specimen/Inter)
- Montserrat: [Google Fonts](https://fonts.google.com/specimen/Montserrat)
- Space Mono: [Google Fonts](https://fonts.google.com/specimen/Space+Mono)

All three families are distributed under the SIL Open Font License 1.1.
